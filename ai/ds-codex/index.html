DeepSeek V4 Flash 接入 Codex 教程

发表于2026-08-03|更新于2026-09-17|编程技术
|总字数:789|阅读时长:2分钟|浏览量:

前言

Codex 是 OpenAI 推出的编程助手客户端。如果希望让 Codex 使用 DeepSeek 提供的模型，可以通过 CC Switch 这类工具把 API Key 和接口地址配置进去，让客户端直接使用第三方模型服务。

CC Switch 可以方便地管理多个 AI 平台的密钥和接口地址等配置信息，支持一键切换，省去了反复修改配置文件的麻烦。

注：客户端和工具版本更新较快，不同版本的界面细节可能略有差异，配置思路是通用的。

准备工作

开始之前，需要准备好以下三样东西：

  1. Codex 客户端：https://openai.com/zh-Hans-CN/codex/
  2. DeepSeek API Key：在 DeepSeek 开放平台创建，https://platform.deepseek.com/usage
  3. CC Switch：https://ccswitch.io/zh/

安装完成后，先不要着急打开 Codex，如果打开了，应该在配置好CC Switch 后重启。下面是配置步骤。

配置步骤

第一步：在 CC Switch 中添加 DeepSeek 供应商

  1. 打开 CC Switch，点击上方的 Codex 页签。
  2. 点击右上角的 加号（+），打开”添加新供应商”界面。
  3. 在 Codex 供应商中，选择 DeepSeek。
  4. 填入刚刚申请的 API Key，然后点击 添加。

第二步：测速并启用

  1. 回到刚才的 Codex 页签界面，找到刚添加的 DeepSeek 供应商。
  2. 点击 测速，如果显示正常，说明 API Key 和接口地址都能正常连通。
  3. 点击 启用，将 DeepSeek 设为当前使用的供应商。

第三步：重启 Codex

启用之后，需要重启 Codex 才能生效：

  1. 完全退出 Codex（如果常驻后台，记得从系统托盘退出）。
  2. 重新打开 Codex 应用。

重启后，应用不再停留在登录界面，而是直接进入已登录状态，说明配置已经生效，可以开始使用了。

验证是否生效

在聊天界面提问它是什么模型，它会回答自己是 Codex。

这说明 Codex 客户端本身没有变化，只是底层的模型服务已经切换为 DeepSeek，可以正常开始写代码和对话了。

常见问题

  • 测速显示失败：先确认网络可以正常访问 DeepSeek 平台，再检查 API Key 是否复制完整，注意不要带上多余的空格。
  • 重启后仍然停留在登录界面：确认是否完全退出了 Codex 进程，必要时在任务管理器中结束 Codex 相关进程后再重新打开。
  • 想换回 OpenAI：回到 CC Switch 的 Codex 页签，把供应商切换回原来的配置即可，无需重新安装客户端。

小提示

  • API Key 相当于账户凭证，不要泄露给他人，也不要提交到公开的代码仓库中。
  • DeepSeek API 按官方计费规则产生费用，使用前建议留意账号余额和用量情况。
  • CC Switch 支持同时管理多个平台的密钥，后续接入其他模型服务也可以沿用同样的方式。

以上就是 DeepSeek V4 Flash 接入 Codex 的完整流程，配置一次之后，后续切换模型就非常方便了。
